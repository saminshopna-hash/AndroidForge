BM Telecom Manager — Android Studio Project
========================================

How to build APK:
1. Install Android Studio on a Windows PC/laptop.
2. Extract this ZIP.
3. Android Studio > Open > select the extracted BM_Telecom_Android_Project folder.
4. Wait for Gradle Sync (internet may be required to download Android build tools).
5. Build > Build Bundle(s) / APK(s) > Build APK(s).
6. Android Studio will show a link to the APK. Copy it to your phone and install.

The app loads the included HTML in Android WebView. JavaScript and DOM storage are enabled for its local records.
Important: this starter version stores data locally on this device/app. Use the app's Backup button regularly.
